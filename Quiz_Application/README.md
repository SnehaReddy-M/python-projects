# Quiz Application 🎯

A simple command-line Quiz Application built using Python.

## Features

- Multiple-choice questions
- Score tracking
- Percentage calculation
- Input validation
- Performance feedback
- Clean and user-friendly interface

## Concepts Used

- Variables
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- User Input
- Input Validation
- f-Strings
- enumerate()

## How It Works

1. The quiz displays a question.
2. The user enters an answer (A/B/C/D).
3. The program checks the answer.
4. The score is updated.
5. After all questions are completed, the final score and percentage are displayed.
