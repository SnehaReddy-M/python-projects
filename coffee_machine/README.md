# Coffee Machine Project ☕

A Python program that simulates a coffee vending machine.

## Features
- Espresso, Latte, and Cappuccino
- Checks available resources
- Accepts coin input
- Calculates change
- Generates reports
- Turns off with the "off" command

## Concepts Used
- Python Dictionaries
- Functions
- Loops
- Conditional Statements

## Run

```bash
python coffee_machine.py
