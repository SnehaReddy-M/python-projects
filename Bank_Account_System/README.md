# Bank Account System

A simple Bank Account Management System built using Python and Object-Oriented Programming (OOP) concepts.

## Features

- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- Savings account with minimum balance restriction
- Demonstrates inheritance and method overriding

## OOP Concepts Used

- Classes and Objects
- Constructors (`__init__`)
- Instance Variables
- Methods
- Inheritance
- Method Overriding

## Project Structure

- `Account` class
  - Deposit money
  - Withdraw money
  - Display balance

- `SavingsAccount` class
  - Inherits from `Account`
  - Overrides the withdraw method to maintain a minimum balance

## Example Output

```text
Balance: ₹2000
Deposited ₹1000
Withdrawn ₹2200
Balance: ₹800
```

## Technologies Used

- Python 3

## How to Run

1. Clone the repository

```bash
git clone <repository-link>
```

2. Navigate to the project folder

```bash
cd bank-account-system
```

3. Run the program

```bash
python main.py
```
