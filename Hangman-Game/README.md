# Hangman Game 🎮

A simple Hangman game built using Python.

## Description

The computer randomly selects a word from a predefined list. The player must guess the word one letter at a time before running out of chances.

## Features

- Random word selection
- Letter-by-letter guessing
- Tracks wrong guesses
- Win and lose conditions
- Beginner-friendly Python project

## Technologies Used

- Python
- Random Module

## How to Run

1. Download or clone the repository.
2. Open a terminal.
3. Navigate to the project folder.
4. Run:

```bash
python hangman.py
```

## Example

```text
🎮 Welcome to Hangman!

Word: _ _ _ _ _ _
Wrong guesses left: 6

Enter a letter: a
✅ Correct!

Enter a letter: z
❌ Wrong guess!
```
