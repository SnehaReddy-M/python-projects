# 🎮 Hangman Game (Python)

A simple command-line Hangman game built using Python.

## 📌 Description

This project is a beginner-friendly implementation of the classic Hangman game. The computer randomly selects a word, and the player must guess it one letter at a time before running out of chances.

## 🚀 Features

* Random word selection
* Letter-by-letter guessing
* Input validation
* Prevents duplicate guesses
* Win and lose conditions
* Beginner-friendly Python project

## 🛠 Technologies Used

* Python 3
* random module

## ▶️ How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python hangman.py
```

## 🎮 Example Output
