# 🔐 Password Generator

A simple Python project that generates a random password based on the user's requirements.

## Features

- Generate secure random passwords
- Choose the number of:
  - Letters
  - Numbers
  - Symbols
- Randomly shuffles characters for better security

## Technologies Used

- Python
- Random Module

## How It Works

1. User enters:
   - Number of letters
   - Number of symbols
   - Number of numbers

2. Program:
   - Selects random characters
   - Combines them into a list
   - Shuffles the list
   - Creates the final password

## Example

```text
WELCOME TO PASSWORD GENERATOR!

How many letters do you want in your password?
5

How many symbols do you want in your password?
2

How many numbers do you want in your password?
3

Generated Password:
aB7#x2P!9
```
