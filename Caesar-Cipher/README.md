# Caesar Cipher

A simple Python implementation of the Caesar Cipher encryption and decryption algorithm.

## Features

- Encrypt messages
- Decrypt messages
- Handles spaces, numbers, and special characters
- Supports any shift key using modulo arithmetic
- Interactive command-line interface

## How It Works

The Caesar Cipher shifts each letter of the alphabet by a fixed number of positions.

Example:

Plain Text:
```
hello
```

Shift Key:
```
7
```

Encrypted Text:
```
olssv
```

## Technologies Used

- Python

## How to Run

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd Caesar-Cipher
```

3. Run the program

```bash
python caesar_cipher.py
```
