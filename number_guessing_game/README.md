#🔢 Number Guessing Game

A simple Python number guessing game.

## Features

- Random number generation
- Easy mode (10 attempts)
- Hard mode (5 attempts)
- User-friendly hints
- Win/Lose conditions

## Technologies Used

- Python
- random module

## How to Run

1. Clone the repository
2. Open terminal
3. Run:

```bash
python number_guessing_game.py
