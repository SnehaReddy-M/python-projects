# Treasure Map 🗺️

A simple Python project that demonstrates:

- Lists
- Nested Lists
- Indexing
- User Input
- Working with a 3×3 Grid

## How It Works

The program creates a 3×3 treasure map.

Example:

['⬜', '⬜', '⬜']
['⬜', '⬜', '⬜']
['⬜', '⬜', '⬜']

The user enters a position such as:

23

Where:
- First digit = Row number
- Second digit = Column number

The program places an **X** at that location.

Output:

['⬜', '⬜', '⬜']
['⬜', '⬜', 'X']
['⬜', '⬜', '⬜']

## Concepts Used

- Python Lists
- Nested Lists
- Indexing
- Input Handling
